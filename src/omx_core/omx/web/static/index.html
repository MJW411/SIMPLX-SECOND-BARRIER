기울기

그리퍼

가동 범위

위 관절 조그의 그리퍼 C 닫기 / O 열기로 원하는 끝까지 움직인 뒤 "지금 위치를 …"을 누르거나, 값을 넣고 "입력값 저장"을 누르세요. 열기·닫기·열림 %는 이 범위 안에서 움직입니다. 그리퍼가 움직일 수 있는 한계는 0~1.05 rad입니다.

시험

열림 정도를 옮기면 바로 움직입니다. 힘 = 물체를 조이는 세기(모터 전류 한도). 열기·닫기 버튼은 아래 "기본 힘"을 씁니다.

저장한 그리퍼 동작

저장한 동작은 작업의 그리퍼 (저장 동작·열림 %) 단계에서 고를 수 있습니다. 자세 이동·홈 이동은 팔만 움직이고 그리퍼는 그대로입니다.

    컨베이어 감시

    입구 카메라 · 헬멧

    헬멧을 쓴 사람이 0.6초 동안 연속으로 보이면 출입문이 열리고, 마지막으로 확인된 뒤 닫힘 시간이 지나면 닫힙니다. 머리(미착용)가 보이면 닫힌 채로 둡니다. 화재 중에는 계속 열려 있습니다.

      누른 기준이 바로 적용됩니다. 아래 값은 지금 적용 중인 기준의 값이며, 저장하면 즉시 반영됩니다.

      정지 < 감속 < 재가동 허용 거리 순이어야 합니다. 사람이 재가동 허용 거리보다 멀어져야 재가동할 수 있습니다. 거리는 사람(손)에서 로봇 팔 표면까지입니다. 인식→정지에 약 0.2초가 걸리므로 정지 거리는 10 cm 이상을 권장합니다.

      무인 시험 감시

      무인 시험용 추가 보호입니다. 보정 여부와 관계없이 동작합니다.

      카메라-로봇 보정

      자동 보정: 조명을 켜고 토크 켜기·재가동 후 누르면, 로봇이 8개 자세를 돌며 주황색 몸체를 기구학 모델에 맞춥니다(약 30초). 수동 보정: 서로 다른 자세 4곳 이상에서 그리퍼 끝을 클릭하거나 ArUco 4x4 마커로 점을 추가합니다.

      인식 모델

      이보다 낮은 확신도의 검출은 무시합니다. 높이면 로봇·물건을 사람으로 잘못 보는 일이 줄지만, 손처럼 일부만 보이는 사람을 놓칠 수 있습니다.

      .engine 파일은 TensorRT로 바로 실행합니다. .pt를 고르면 바로 쓰기 시작하고, 뒤에서 TensorRT 엔진으로 변환한 뒤 자동으로 바꿉니다.
